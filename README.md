# Проєктний офіс відновлення громади · Соснівка

**Community Recovery Project Office · Sosnivka** — серйозна навчальна гра з дисципліни
«Проєктна діяльність органів публічної влади» (КНЕУ, 28 «Публічне управління та адміністрування»).

Двомовна версія: **українська (за замовчуванням) та англійська** — перемикач УКР | ENG у шапці,
мова тримається в адресі (`?lang=en`).

## Що це

Гібридна модель гейміфікації за дизайн-документом v1.0:

- **Хаб «Проєктний офіс»** — кар'єрна траєкторія службовця (4 посади за XP), чотири індикатори
  громади Соснівки (Добробут, Довіра, Стійкість, Бюджетний результат), мапа курсу
  «семінар = гра», полиця бейджів.
- **Два акти**: Акт I «Тримаємось» (воєнний стан: критична інфраструктура, укриття,
  енергостійкість) → Акт II «Відбудовуємось» (школи, житло, донорські програми) →
  фінал: капстоун «Заявка на відбудову» + симулятор екзамену.
- **15 семінарів = 15 міні-ігор** + 2 бос-файти (репетиція модульних робіт Moodle).
- **Перша гра вже playable**: «Проєкт чи рутина?» (семінар 1) — сортування 12 справ
  управління на таймері + розподіл учасників проєкту за ролями (замовник, виконавець,
  користувач, куратор). Інші 16 ігор — у розробці (картки «🚧 у розробці»).

Принципи серйозної гри: жодних бойових сцен чи видовищних руйнувань — війна присутня
лише як управлінські умови; механіки надихнуті Дія.Відновлення, єВідновлення,
реєстром пошкоджень та Ukraine Facility. Місто, персонажі й кейси повністю вигадані.

## Технології

Next.js 16 (App Router) · React 19 · TypeScript · Tailwind CSS 4. Без бази даних,
без облікових записів, без сервера: статичний сайт, прогрес гравця — у `localStorage`
(ключ `pm-office-v1`) з експортом/імпортом кодом відновлення.

## Запуск локально

```bash
bun install   # або npm install
bun run dev   # http://localhost:3000
```

Продакшн-збірка:

```bash
bun run build
bun run start
```

## Деплой (GitHub → Vercel)

1. Код у репозиторії `pm-office` (гілка `main`).
2. Vercel → **Add New → Project** → імпорт репозиторію `pm-office`.
3. Нічого не змінюйте у налаштуваннях — фреймворк визначиться сам (Next.js).
4. **Deploy** — за ~хвилину сайт живе на `https://pm-office-<…>.vercel.app`.

Наступні публікації — автоматичні: кожен push у `main` запускає новий деплой.

## Структура

```
src/
  app/
    layout.tsx              # метадані, шрифти
    page.tsx                # оболонка: шапка, перемикач мови, перехід хаб ↔ гра
    globals.css             # Tailwind 4
  lib/
    pm-i18n.tsx             # двомовний шар uk|en (useL, Bi, LangSwitch, useTitle)
    pm-office.ts            # дані й чиста логіка: кар'єра, індикатори, бейджі,
                            #   мапа курсу, картки гри, XP/бали, прогрес localStorage
  components/pm-office/
    hub.tsx                 # хаб: кар'єра, індикатори, мапа курсу, бейджі, етика,
                            #   код відновлення прогресу
    sort-game.tsx           # гра «Проєкт чи рутина?»: 2 рівні, таймер, пояснення
```

## Як додати наступну гру

1. Дані гри — новий розділ у `src/lib/pm-office.ts` (картки/сценарії, bilingual `{uk, en}`).
2. Компонент гри — новий файл у `src/components/pm-office/` (за зразком `sort-game.tsx`).
3. Оболонка: у `src/app/page.tsx` додати view та кнопку запуску; у хабі замінити
   картку «🚧 у розробці» на кнопку «Грати».
4. Лінт (`bun run lint`) → commit → push → Vercel збере сам.
